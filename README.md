# 공공채용 OS

공기업·공공기관 채용공고를 한 화면에서 비교하고 개인 지원 현황을 관리하는 Flask 대시보드입니다.

## 핵심 기능

- JOB-ALIO 최신 공고 수집
- 기관, 직무, NCS 검색
- 직무·지역·신입/경력·학력 체크박스 다중 선택(항목 내 OR, 항목 간 AND)
- 학력 표기 정규화: 무관, 고졸, 전문학사, 학사, 석사, 박사
- 채용 인원, 접수 기간, D-day, 전형 단계, 원문·첨부파일 통합 표시
- ALIO 최신 결산 기준 `기본급 + 고정수당` 월 환산
- 관심 → 서류준비 → 서류제출 → 필기예정 → 면접예정 → 최종결과 지원 파이프라인
- 준비 메모와 다음 행동 날짜 저장
- 검색 조건 이름 지정 저장 및 재사용
- 모바일 반응형 UI

## 급여 표시 원칙

월 고정급 참고값은 ALIO 신입사원 초임 중 최신 **결산연도**의 기본급과 고정수당을 합산해 12개월로 나눈 값입니다. 실적수당, 성과상여금, 경영평가성과급은 제외합니다.

ALIO 신입초임은 대졸·사무직·군미필·무경력 최하위 직급 기준이므로 특정 공고의 직무·경력·고용형태에 적용되는 확정 급여가 아닙니다. 공고문이나 보수규정에 직접 금액이 명시되지 않은 경우 반드시 근거 링크에서 확인해야 합니다.

## 실행

```bash
uv venv .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
.venv/Scripts/python.exe app.py
```

브라우저에서 `http://127.0.0.1:5070`을 엽니다. 첫 화면에서 **최신 공고 가져오기**를 누르면 JOB-ALIO 2페이지를 수집합니다.

## 테스트

```bash
.venv/Scripts/python.exe -m pytest -q
```
